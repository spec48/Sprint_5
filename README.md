# Sprint_5: UI-автотесты Selenium Python для учебного сервиса «Доска»
- Тесты на функциональность «Регистрация пользователя».
- Тесты на функциональность «Login пользователя».
- Тесты на функциональность «Logout пользователя».
- Тесты на функциональность «Создание объявления».
___
## Используемые библиотеки
- pytest
- selenium 4
___
## Запустить автотесты можно командой ```pytest -v``` из папки проекта Sprint_5
___
## Структура проекта
- tests/ — python package с тестами.
  - test_user_registration.py - тесты на регистрацию пользователя.
  - test_user_authorization.py - тесты на проверку login, logout пользователя.
  - test_create_an_advertisement.py - тесты на создание объявления.
- conftest.py — фикстуры.
- helpers.py — вспомогательные функции.
- urls.py — файл с url.
- data.py — файл с данными.
- locators.py - файл с локаторами
- README.md - описание проекта
- .gitignore
